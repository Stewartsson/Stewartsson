### 🚀 Key Projects

* **[NeuroGuardian](https://github.com/Stewartsson):** An integrated 3-in-1 IoT ecosystem for diabetic patients, featuring fall detection and remote foot ulcer scanning[cite: 1, 2].
* **[Smart Healing System](https://github.com/Stewartsson):** An active IoT theranostic bandage that continuously monitors wound micro-climates (pH & temperature) and triggers automated 405nm Blue Light therapy to prevent amputations[cite: 2].
* **[Smart Crutch System](https://github.com/Stewartsson):** A wearable ESP32-based smart crutch utilizing an MPU6050 and GPS for real-time fall detection, sending instant alerts with live location via Bluetooth[cite: 1, 2].
* **[Calculator using FPGA](https://github.com/Stewartsson):** A VLSI-based calculator built with an efficient RTL design on the Xilinx ZedBoard FPGA, using a modular ALU and Carry-Select Adder to lower processing delay[cite: 1, 2].
